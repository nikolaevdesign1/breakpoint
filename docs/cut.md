# Срезанные углы у фото и видео

Только фото и видео. Текст, кнопки, поля и плашки остаются квадратными. Стили: `src/css/site/cut.css`, подстройка угла: `src/js/site/cut.js`.

```html
<figure class="cut cut--a"><img src="..." alt="..."></figure>
```

| Класс | Срез |
|---|---|
| `.cut` | база: `overflow: hidden`, плавный переход clip-path 2.4s |
| `.cut--a` | правый верхний, 45° |
| `.cut--b` | левый нижний, 45° |
| `.cut--c` | левый верхний, пологий |
| `.cut--d` | два угла: левый верхний и правый нижний |
| `.cut--e` | правый нижний, крутой |
| `.cut--f` | правый верхний и левый нижний, разной глубины |

- Глубина по горизонтали `--cut-x` (по умолчанию 9% ширины; 8-10% безопасно для лиц). Меняется на элементе: `style="--cut-x: 8%"`.
- `cut.js` (ResizeObserver) выставляет `--cut-y`, чтобы наклон был честные 45° при любой пропорции.
- Hover / фокус внутри: срез мягко выравнивается до 35% (медленно, `--dur-5`). Для reduced-motion без перехода.
- Контейнеру нужен размер (aspect-ratio или высота).
- Параллакс: срез на контейнере, `parallax.js` двигает `img`/`video` внутри.
- `data-cells` (квадратная сборка фото): для кадров с `.cut` ступенчатый срез отключён, остаётся сборка из квадратов.

## Где применено

home: галерея сообщества (`.cgal__media`, a-f), превью услуг (`.services__thumb`), облако тренеров (`.cc-card`, вариант по ключу); about: три фото главы `.rc__photo` (между главами в лёгкой версии, в конце страницы в 3D). Не применено: полноэкранные герои на тёмной подложке (hero главной, hero турниров, баннер «Book a court»: срез открывает тот же тёмный фон и не виден), аватары 32px в отзывах, coaches и booking.

## Концепция «Корт из квадратов» (предложение, ждёт выбора)

Корт = сетка квадратов. Вводим единую сетку на весь сайт (квадрат = 1/24 ширины экрана, на мобильном 1/8), все квадратики во всех эффектах ложатся на неё — так помехи выглядят системой, а не случайным шумом. Цвета квадратов: в основном Deep Black `#121211` и белый, акцентами Rich Red, Finch, Malibu Sun, Woodsy Brown. Референсы: Cantor8 (ступенчатые края, пиксельный лоадер, палитра-полосы).

**Разбор cantor8.io (2026-10-02):** GSAP + ScrollTrigger + Lenis, как у нас. Переходы между секциями — полоса-сетка `.pixel-grid` 25 колонок × 6 рядов (150 квадратов по ~59px на 1440px, т.е. ширина/24.4), лежит поверх стыка секций (высота ~350px); квадраты в цвете соседней секции включаются/гаснут по скроллу, несколько светлых акцентных квадратов. Есть отдельный слой `.transition_cubes` для переходов между страницами. Заголовки: PP Neue Montreal 56px / 400 / интерлиньяж 1.0 — подтверждает шкалу из правки 23.

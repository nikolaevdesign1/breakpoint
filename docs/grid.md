# Сетка сайта

12 колонок, отступ от края `--edge` (16px на десктопе, 12px на телефоне до 640px), gutter `--grid-gap` 16px. Токены в `src/css/site/tokens.css`, классы в `src/css/site/grid.css`. Шапка, `.section` и футер берут отступ из `--edge` (`--gutter` и `--frame` теперь его алиасы), поэтому края совпадают на любой ширине. Booking-сцена сетку не использует.

## Классы

| Класс | Что делает |
|---|---|
| `.container` | на всю ширину, `padding-inline: var(--edge)`. Для блока вне `.section` (внутри `.section` боковой отступ уже есть) |
| `.grid` | 12 колонок, `column-gap: 16px`. Ставить внутрь контейнера или секции |
| `.grid--rows` | добавляет вертикальный gap (`--grid-row`, по умолчанию 24px) |
| `.grid-bleed` | вытягивает блок к краям экрана (отрицательные боковые отступы) |
| `.col-1` ... `.col-12` | сколько колонок занимает ребёнок |
| `.start-1` ... `.start-12` | с какой колонки начинается |
| `.t-col-N`, `.t-start-N` | то же для планшета, 641-1000px |
| `.p-col-N`, `.p-start-N` | то же для телефона, до 640px |
| `.p-shift-1`, `.p-shift-2` | на телефоне сдвиг на 1-2 колонки |

Без `p-*` классов ребёнок `.grid` на телефоне занимает всю строку (одна колонка).

## Пример: ступенчатая раскладка

```html
<section class="section">
  <div class="grid grid--rows">
    <h2 class="h2 col-6">Heading</h2>
    <p class="col-4 start-8 p-shift-1">Paragraph</p>
    <p class="col-2 start-11 p-shift-2">Caption</p>
  </div>
</section>
```

Соседняя секция зеркалит: заголовок `start-5`, абзац `start-1`. Всегда по началу колонки, не произвольным margin. Порядок в HTML равен порядку чтения.

## Dev-подсветка

На dev-сервере клавиша `G` показывает/скрывает 12 колонок (`src/js/site/grid-dev.js`, подключается под `import.meta.env.DEV`, в прод-сборку не попадает). Не срабатывает в полях ввода.

## Проверка краёв

Левый край логотипа шапки, контента секции и футера совпадает с `--edge` на 1440 / 1920 / 390.

# Параллакс

Один модуль: `src/js/site/parallax.js`. GSAP ScrollTrigger со scrub 1.2s; Lenis (`window.__lenis`, через Locomotive в `site.js`) питает ScrollTrigger, поэтому отдельной подписки не нужно. Layout не трогается, CLS нет. `will-change` ставится только пока кадр на экране.

## Фото и видео (строка 62): автоматика

Каждый `img` и `video` на странице (кроме booking) сам двигается внутри своего кадра медленнее страницы. Разметка не нужна.

- Кадр: ближайший предок из списка `.cut, .media, figure, .cc-card, .mt, .book-banner, [class*="__media"], [class*="__photo"], [class*="__thumb"]`, иначе родитель. Если кадр не обрезает (`overflow`), скрипт ставит `overflow: clip`.
- Двигается сама картинка через CSS-свойства `translate` и `scale` (переменные `--par-y`, `--par-s`, правило `[data-px]` в `cut.css`). Они складываются с `transform` картинки (hover-зум, следование за курсором в галерее) и не мешают `clip-path` кадра: срез `.cut` и его hover-выравнивание на контейнере, движение внутри.
- Ход: 10 / 14 / 12% высоты кадра (соседние кадры получают разные, по кругу), масштаб = 1 + ход + 0.04 (1.14 / 1.18 / 1.16), поэтому края не открываются. Scrub 1.2s. Картинка и видео в одном кадре (poster + video в hero турниров) едут вместе.
- Кадр в первом экране использует весь ход (старт `clamp(top bottom)`).
- Закреплённые сцены (sticky: услуги, горизонтальная галерея, облако тренеров, сцены с `position: sticky`): кадр на экране стоит, поэтому дрейф идёт по прогрессу всей сцены (предок sticky -> его родитель, `top top` ... `bottom bottom`).
- Пропускаются: `position: fixed` (лайтбокс, модалки), картинки уже 120px (аватары, мелочь; исключение `.cc-card`), `object-fit: contain` (портреты-вырезки, масштаб обрезал бы их), `nav`, `.preloader`, `.cgal-view`, `.msg`.
- Картинки, добавленные скриптами позже (MutationObserver, 300ms), подключаются сами; после этого один `ScrollTrigger.refresh()`.
- Touch: ход вдвое слабее, слабые устройства (`deviceMemory <= 4` или `hardwareConcurrency <= 4`) на touch: выключен. `prefers-reduced-motion`: выключен (картинка не масштабируется).

## Атрибуты

| Атрибут | Где | Смысл |
|---|---|---|
| `data-parallax="0.12"` на кадре | фото, видео | свой ход (доля высоты кадра, 0.04-0.2) вместо кругового 0.10 / 0.14 / 0.12 |
| `data-parallax="0.4"` на любом другом элементе | текст | сдвиг до ±24px × коэффициент. Плюс = медленнее страницы (отстаёт), минус = быстрее. Диапазон -1..1 |
| `data-parallax="off"` | любой | выключить (действует и на всё внутри) |
| `data-parallax-auto="off"` на предке | секция | выключить авто-режим внутри |

## Текст (строка 25)

`h1[data-lines]`, `h2[data-lines]`: 0.4 (крупное чуть медленнее); `.lead`: -0.3 (мелкое чуть быстрее). Пропускаются элементы внутри sticky и внутри `[data-reveal]` / `[data-bounce]`: они сами анимируют transform. Текст двигается через `transform`, картинки через `translate` / `scale`: конфликтов нет.

## Правила

- Не вешать текстовый `data-parallax` на элемент, у которого уже есть `data-reveal` или своя GSAP-анимация transform; оберните его.
- Свою анимацию картинки писать через `transform` (как сейчас), не через `translate` / `scale`.
- Новая картинка в контейнере без `overflow` получит `overflow: clip`; если у кадра есть выступающие потомки (подпись за краем), задайте ему `overflow: hidden` заранее и поставьте им отдельный слой.
